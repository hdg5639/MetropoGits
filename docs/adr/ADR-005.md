# ADR-005: Genuine 3D viewer for the stable v1 release

- Status: Accepted
- Date: 2026-10-17
- Decision owners: Project maintainer
- Applies to: DEC-009 and the official interactive viewer

## Context

DEC-009 requires two distinct render targets: a deterministic CPU-friendly
README preview and an interactive 3D static viewer. The current viewer is an
interactive isometric projection drawn through a 2D canvas. It provides useful
navigation, selection, filtering, and evidence inspection, but it does not
satisfy the ordinary meaning of a genuine 3D viewer.

MetropoGits is intended to be a visually distinctive open-source code-city
tool. Camera freedom and spatial inspection are part of that identity, while a
fast deterministic image remains essential for README use, CI, accessibility,
and environments without WebGL.

## Decision

The stable v1 release MUST include a genuine interactive 3D viewer.

- The 3D renderer consumes the existing versioned City Scene and UCG contracts;
  it must not create a second semantic or layout model.
- It supports camera orbit, zoom, building selection, dependency inspection,
  and the existing evidence/category filters.
- The current CPU-friendly SVG and isometric 2D renderer are retained for
  deterministic previews and as a graceful fallback when WebGL is unavailable.
- CI and preview generation remain GPU-independent. A missing WebGL context
  must explain the fallback instead of failing the artifact.
- Introducing the 3D renderer does not authorize a backend, runtime analysis
  service, repository-code execution, or remote asset requirement.

The existing 2D implementation may be described as a preview or candidate,
but it is not sufficient by itself for the stable v1 release.

## Consequences

- DEC-009 is no longer awaiting an owner choice; implementation and visual
  validation of the 3D path are now the remaining compliance work.
- Both renderers must preserve exact entity, evidence, and aggregated edge IDs.
- Viewer tests need a deterministic non-GPU contract layer, JavaScript syntax
  checks, a WebGL-capable browser smoke test, and an explicit fallback test.
- Dependency or vendored-asset additions require license and supply-chain
  review before they enter the static artifact set.

## Rejected alternative

Treating the existing isometric canvas as the official v1 3D viewer was
rejected because it would weaken the already locked DEC-009 requirement and
the intended exploratory city experience.
