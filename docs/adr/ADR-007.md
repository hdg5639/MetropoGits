# ADR-007: Deferred opt-in public deployment

- Status: Accepted
- Date: 2026-10-17
- Decision owners: Project maintainer
- Applies to: Repository visibility, GitHub Pages, and generated city metadata

## Context

The official MetropoGits experience is intended to use a static GitHub Pages
demo built by GitHub Actions. Generated graph and city artifacts expose source
paths and architecture, so publication is a deliberate privacy boundary rather
than a routine build step. The project is not yet visually ready for its public
repository conversion.

## Decision

GitHub Pages remains the selected deployment path for the official interactive
demo, but public repository conversion and Pages activation are deferred until
the maintainer explicitly approves them.

- No development task, test, push, or release-readiness update may change the
  repository to public visibility or enable Pages implicitly.
- The checked-in CI workflow remains read-only and does not deploy.
- The Pages workflow stays an example for users; it is not installed into this
  repository's active workflows while the deferral is in force.
- Generated metadata must be inspected before any eventual publication.
- After explicit approval, the deployment must use static artifacts, scoped
  `pages: write` and `id-token: write` permissions only in the deployment job,
  and a verified repository-subpath URL.
- Users remain free to generate and host their own cities independently.

## Promotion gate

AC-010 and fresh-repository publishing remain blocked while the deferral is in
force. They may become automated only after an explicitly authorized hosted
deployment proves the README-to-Pages route. A successful build artifact alone
does not satisfy this gate.

## Consequences

- Local development, the composite Action, and private CI validation continue
  without publication credentials.
- The Apache-2.0 license does not itself authorize changing repository
  visibility or publishing source-derived artifacts.
- Stable v1 can be prepared privately, but its public release is not declared
  until the maintainer lifts this gate.
