# ADR-022 — Street-facing experimental parcels

Status: user-approved bounded experiment, 2026-10-19. Not default adoption.

The user requests building orientation and local parcel/street coordination,
including better use of empty frontage. Extend ADR-020/021's fixed-building
restriction only in explicit `--frontage-parcels` output. Preserve canonical
City/UCG, identities, directory ownership, dimensions, heights and evidence.
Derived `street-parcels/0.1` records original and physical placement separately.
Do not pretend this is a new canonical City rotation field or silently change
the normal layout. The package must disclose derived geometry and export it.

Orient whole building archetypes to nearby physical streets, not random angles
or inferred geographic north/sunlight. Translate at most seven world units
within the same directory footprint. Existing relationship endpoints and civic
entrances remain fixed: every old doorway must remain on the new perimeter;
incompatible doorway anchors veto relocation. Square parcels can quarter-turn
without moving their perimeter or doors. Do not alter trips to
make a cosmetic placement pass. Reject building/building and full-width road
collisions, concave-boundary escape and insufficient clearance. Deterministic
ordering, bounded candidates and explicit caps are mandatory.

One file remains one building. No invented buildings, semantics or traffic fill
empty space. Movement may reduce frontage distance and use leftover wedges;
total building footprint area is unchanged. Report both rather than claiming
that every empty plot disappeared. This is local parcel adaptation to the
reconstructed street network, not global joint city optimization.

WebGL, Canvas, picking, selection and CPU previews must consume the same physical
corners. Aggregates containing changed footprints are expanded consistently so
Overview cannot show stale axis-aligned replacements on top of moved files.
Inspector discloses street-derived orientation and displacement. All original
route endpoints remain on their owning physical building. Existing unmodified
modes retain behavior. Compare unknown/sparse and dense repositories, actual
same-camera captures, repeated output, obstacle/ownership checks, relation
identity and Synthetic caching before commit/push.

Phase A includes a small non-semantic facade canopy inside the certified envelope
to make the front readable. It does not assert a new source element. Metadata
contains frontage edge/point, facing vector, selected street, gap and pinned doors.
Native model aspect ratios are retained, not shrunk to force diagonal fits.

Follow-up sequence requested by the user: Phase B derives a primary local axis
from dominant adjacent roads and re-parcels a whole block; Phase C treats corner
lots/intersection setbacks. Then consider footprint families and road hierarchy
placement bias. Large roads cannot invent roles or inflate source metrics. These
broader steps are not claimed by the bounded orientation implementation.
