# ADR-023 — Coordinated block orientation and occupied ground

Status: user-requested bounded experiment, 2026-10-19; not default adoption.

The user approves continuation of local block/entrance planning and specifically
requests less ground around sparse building groups. ADR-022 pins every original
door coordinate, preventing real oblique placements. In a new explicit block
option, permit a bounded rigid transformation of a rectangular leaf block and
its internal streets together. Logical relations, IDs, evidence, building sizes
and directory ownership remain unchanged. Canonical City/UCG stay untouched.

A fixed outer cage is the original rectangular owner footprint. An inner cage
encloses every member building. Rotate/translate the inner cage rigidly toward
a nearby physical street direction; outside geography stays fixed. Triangulate
the intervening ring and reject every inverted/degenerate triangle. This gives
a continuous piecewise-affine map with a fixed outer boundary. Apply it to road
surfaces, paint, exact inspection paths, Synthetic and building parts together.
Split all crossing geometry at triangle boundaries. Preserve each trip pairing,
not necessarily its old physical doorway coordinate. Never manufacture a new
semantic route. Limit block size, displacement, proposals and generated pieces.
Keep whole-group fallback when no safe candidate fits. Maximum physical block
corner displacement is fourteen world units (two original cells); unlike the
seven-unit single-building pilot, the whole block and its entrances move together.
No random orientations. Partial alignment is disclosed when full alignment fails.

Separately distinguish allocated directory area from visible occupied ground.
Build tight, bounded ground pads around nearby actual building footprints;
merge neighboring supports without filling distant empty ownership reserves.
Use these pads in the normal city presentation and retain full directory ground
in Structure overlay. Preserve original district IDs, selection and inspector
membership. A smaller displayed pad is NOT a smaller canonical district or a
claim of improved physical packing. Report displayed ground area separately.

WebGL, Canvas and README must share the same derived physical geometry and
ground plan. Aggregates must not draw stale locations over changed footprints.
Keep this limited rigid block pilot distinct from future full parcel subdivision,
corner-lot reassignment, inter-district compaction and default adoption. Compare
sparse/unknown and dense repositories, same-camera captures, exact continuity,
area/ownership, repeated output and Synthetic cache behavior before delivery.
