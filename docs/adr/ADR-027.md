# ADR-027 — Reproducible world outline variation

Status: user requested variation beyond the fixed ellipse, 2026-10-19.

Add opt-in `--outline varied`, leaving `ellipse` and all prior world bytes as
the default. Derive a separate `seeded-convex/1` stream. Seed-selected compact,
elongated, angular or asymmetric silhouettes vary vertex count, polar spacing,
radius, aspect, shear and rotation before convex-hull canonicalization. Scale
the result to the actual land budget, then partition and plan inside it. This
changes real land, parcels and physical routes, not only a decorative coastline.

Restrict this step to convex connected land, the proven input of the existing
geometry kernel. Do not promise concave bays, islands, terrain or water. Those
require a separate bounded polygon-boolean design. Same seed/options reproduce
the same world; variation is not random on every refresh or commit revision.

Varied outlines use additive `flat-world/0.4`, explicit outlinePolicy,
outlineVersion and outlineFamily; existing experimental World versions remain
valid. Hints require a matching outline policy and keep the previous envelope
while capacity fits. Policy/seed changes explicitly replan; no source ID,
building dimension, evidence or graph relation changes.

Verify multiple outline seeds, convexity/area/topology, nearby-file hints and
legacy default equivalence. Run the four maintained corpus snapshots with all
five planning options available, inspect real static/browser output, and expose
a controlled five-profile atlas so capacity fallback is not mistaken for a
missing implementation. Record failed seeds/capacity cases honestly.
