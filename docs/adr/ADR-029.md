# ADR-029 — Soft influence over the existing street-based world

Status: maintainer requested base-pattern preservation and graph-aware mixed
placement on2026-10-19. Explicit opt-in experiment; hard zoning stays readable.

## Problem and decision

Hard role quarters worked technically but sorted similarly colored files into
production lines. Keep the five existing planning grammars and seeded outline
as physical geography. Add `--zoning soft`, compatible with every `--planning`
policy and `--outline varied`. Do not rebuild every neighborhood as a GRID or
inflate its land merely to enforce homogeneous semantic membership.

Generate streets/frontage parcels first using the existing world engine. Source
roles define functional centers and capacity-weighted power influence cells,
not exclusive building ownership boxes. Reassign actual files to existing
occupied sites within their principal directory/service district, using sparse
source-backed dependency affinity and a weak center preference. Every occupied
site, frontage and physical street is retained; no decorative buildings/edges.
Restrict swaps to equal source footprint dimensions. Recompute whole building
meshes/rotation/entrances from the destination frontage and reroute exact UCG
trips once after assignment. No geometry inferred from runtime traffic.

Use bounded deterministic local search, spatially indexed candidate addresses,
bounded graph degree and a per-district scoring budget. Publish before/after actual
dependency lengths and energy, work counters and any pinned-hint limitations.
Unconnected/unsupported files remain useful neutral structures. Do not invent
supporting roles to meet a mixing quota or imply that proximity creates an edge.

Preserve logical role-center membership separately from actual influence-region
occupants. A center's evidence never claims that all occupants share its role.
`softZoning` is additive in World, `flat-soft-zoning/0.1`; separate
`planning/0.2-experimental` records this changed planning interpretation.
Existing City/UCG, source IDs, hard-zone IDs and older documents are unchanged.
Display derived influence-region membership, original source ownership, center
claims and actual per-file evidence distinctly in both browser renderers.

Compatible previous worlds pin existing file addresses; new/changed geography
is explicitly diagnosed. Do not silently optimize all old files after an edit.
Cold opt-in geometry is deterministic, not promised identical to hard sorting.

## Appearance and scope

In a separate verified work unit, use seeded neutral wall materials with small
role accents; selection/role filters may restore strong categorical emphasis.
Browser and CPU read the same material plan. Preserve all height/size facts;
do not hide an invalid layout with decoration or random building-size changes.

Retain current seeded outline families for the first soft-zoning ablation.
Non-convex coastlines need a versioned decomposition/boolean geometry decision;
do not send a concave polygon into the current convex clipping kernel. Evaluate
overall composition after fixing sorting/materials before adding more patterns.

## Gates

Four-repository before/hard/soft comparison, fresh small/unknown pipeline, exact
source/edge/site/street conservation, whole-frame/clearance validation, repeated
bytes, hinted small edits, actual WebGL/Canvas/SVG and measured time/data costs.
Record visual failures and limits, not an unqualified "natural city complete".
