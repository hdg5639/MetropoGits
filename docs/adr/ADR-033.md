# ADR-033 — Continuous district fabric and disclosed flat landscaping

Status: maintainer-requested visual extension, 2026-10-19. Derived World export
only; no City/UCG, source identity, physical layout or routing contract change.

## Intent and limits

The maintainer accepts adaptive0.3 as a better working reference, but rejects
both the crossed-stencil appearance and detached mini-campuses. Even the curved
scripts example is a direction reference, not an island to reproduce. Internal
neighborhoods should retain a local order inside continuous parent geography.
Do not delete the restored orbital families, undo actual cross-role mixing, or
hide structural road defects under props.

The first bounded slice restores one ground material per principal district.
Administrative neighborhood cuts remain selectable/inspectable but do not get
separate solid ground plates. Derive flat green pockets and low-poly trees only
in certified free space after all physical streets, parcels and entrances exist.
Use a shared seeded spatial field, not a new ecological seed per neighborhood;
greenery must not trace every administrative border or form a fence around it.
Retain the parent tint and keep source-role colors unchanged in this work unit.

## Presentation contract

Emit a separate `landscape/0.1` presentation artifact and the same data in the
derived browser adapter. It is explicitly decorative, contains no entity/edge
claims, and is not a new City decoration/archetype. CPU SVG, WebGL and Canvas
consume identical polygons/tree geometry. Structure overlay removes the layer
for inspection. No dependencies, fake traffic or paths are added for greenery.

Clip/subtract candidate green polygons against actual full-width streets,
junction clearance and entire source parcels. Trees must fit in retained green
land. Bound spatial indexing, candidate count, polygon fragmentation and output;
optional presentation exhaustion retains certified output with diagnostics and
never changes or drops a source building/route. Keep greenery cached and batched
with static geometry; Synthetic must not rebuild it on animation frames.

This is **flat landscaping**, not implemented elevation, hydrology, protected
buildability fields, rivers, bridges or tunnels. Dense pattern crossings remain
a separate road-planning issue; disclose them in real before/after review.

## Gates

- Same World/City/UCG bytes, parcel frames, roles, neighborhood membership,
  physical streets and exact source trips before/after this export change.
- Deterministic bounded landscaping with no parcel/full-width road/entrance
  invasion; clear decorative legend and no selectable fake code elements.
- Actual OJ/GJ plus low-semantic corpus and maintained fresh fixture; same-camera
  WebGL, CPU and Canvas views, natural interior continuity and parent identity.
- Existing inspector, source traceability, navigation and Synthetic regression
  checks; report added geometry/time, not a universal FPS claim.
