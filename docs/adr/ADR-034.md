# ADR-034 — Shared junction access without moving neighborhoods

Status: next bounded opt-in correction requested by the maintainer, 2026-10-19.
This extends existing urban detour permission, not source semantics or City/UCG.

## Problem

Adaptive0.3 protects every used physical segment, so it can only remove a few
unused pieces. Parent and local streets still produce close redundant forks.
Adding greenery or thinning an entire orbital family does not solve this.

## Bounded experiment

Add `--street-policy shared` only for adaptive neighborhoods, with an explicit
`flat-adaptive-neighborhoods/0.4` generator enum. Default original0.3 remains an
ablation; its planner, pattern seeds, source groups and building frames stay
unchanged. Pattern metadata remains adaptive-patterns/0.3. This is a compatible
experimental version addition, not a public City/UCG migration.

Keep every reserved parent corridor/orbit, principal boundary, building driveway
and actual tangent frontage. Consider whole nonprotected chains between existing
junctions, not arbitrary sampled curve fragments. Remove a redundant chain only
when a bounded existing alternate goes through shared parent/busy infrastructure.
Do not add/move pavement, fabricate roundabouts or turn administrative cuts into
streets. Junction sharing must be real physical reuse, not a rendering mask.

Maintain exact source-target/edge identities. Affected full-trip witnesses must
fit max(original length*1.5, original length+12 world units), permitting a short
block detour as previously authorized. Charge cumulative changes against the
ORIGINAL trip, not the last accepted detour. Local replacement length is also
bounded. Reject a candidate if any affected trip fails. Rebuild the exact route
graph on the retained physical infrastructure and independently check all final
trip budgets; otherwise retain the certified original streets/routing.

Bound indexing, candidate attempts, search states and route-update work. Exhaustion
must retain certified geometry, preserve every entrance and disclose the limit.
No global district reroll, role sorting or selective repository-name exceptions.
Original0.3 and shared0.4 hints may share geographic anchors because this pass
changes only roads after unchanged lot planning; older incompatible geography
remains rejected. Never call equal seeds proof of unchanged geometry: compare it.

## Gates

Keep exact parent/district land, whole building frames, neighborhood/core/mixed
memberships and source City/UCG bytes. Preserve every required frontage and main
curve, full-width clearance, entrance connectivity, exact trips and edge coverage.
Verify actual rerouting/road removal, bounded cumulative detours, deterministic
bytes, compatible hints and unchanged old modes. Compare OJ/GJ/unknown corpus in
same-camera CPU/WebGL/Canvas, including the existing flat greenery and Synthetic
static-cache checks. Reject visual monotony even if length/road count improves.
