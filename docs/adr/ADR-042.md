# ADR-042 — Evidence-bounded courtyard campus pilot

Status: user-authorized Road Network and Campus Planning continuation,
2026-10-19. CP-00/01 bounded vertical slice; not all campus variants.

## Outcome

Explicit experimental `--campus` requires routed adaptive neighborhoods. Keep
directory ownership, the parent's five-pattern arterial skeleton, global terrain,
zone polygons, original file dimensions/roles and every source relationship.
Choose at most one feasible campus neighborhood per parent, using deterministic
weighted choice among evidenced test/compact internally related clusters.
Directory names alone do not qualify. The grammar is physical morphology,
never a claim that code is a university, research facility or unknown framework.

Reserve one to three open courts BEFORE local parcels and walking circulation.
Fit road-facing/corner-rotated real-file plots around shared courts; connect real
entrances through actual pedestrian loops/spurs to existing physical streets.
Do not draw dependencies on ornamental paths or build a driving loop around
every lawn. Keep original access/routing traceability. Capacity, terrain,
clearance or bounded connector failure retains the original local grammar,
with a reason, without enlarging the entire city to force CAMPUS.

Frozen-corpus feasibility correction: making every file in a large neighborhood
fit courtyard rings would erase the macro skeleton or inflate land. The pilot
therefore constructs an explicit MIXED_CAMPUS pocket inside the same evidence
neighborhood. Only its real selected members use court lots; remaining members
keep the original local grammar. Local unoccupied address candidates/lanes may
be replaced before file assignment, but the protected backbone/zone/terrain stay
fixed. Disconnected unused candidate lanes are pruned before placement; no
occupied source building or relationship may be dropped. Inspectors must state
pocket membership, not mislabel the whole neighborhood as a pure campus.
Finish original capacity repairs before attempting a pocket, so that campus
eligibility cannot change unrelated neighborhood allocations. Check original
file pairs across parent boundaries as well as inside them for eligibility;
do not mistake same-parent affinity filtering for complete external coupling.
Reject court candidates with fewer than three non-corner frontage sides or
more than120 square world units of lawn per potential actual member. These are
bounded visual fit guards, not code-size or research facts.

## Contract and compatibility

Optional World/planning `campusPlan`, pinned `campus-plan/0.1`, carries decisions,
evidence IDs, actual member/anchor IDs, reserved courts and walkways. Blocks
retain their base planningProfile/mode and add urbanGrammar MIXED_CAMPUS;
selected plots use blockProfile CAMPUS with a corresponding derived plan.
City/UCG schemas and IDs do not change. Flag off retains old canonical output.
Cross-policy geography hints are incompatible; same-policy hints retain actual
slots where feasible. A courtyard reservation is not a fake source entity.

Prepare geometry offline. The existing authoritative physical graph includes
walking access; pedestrian spans are explicitly classified in streetPlan instead
of painted as vehicular collectors. Synthetic remains illustrative, bounded,
and follows only stored source-pair paths; no path creates a new source relation.

Consumers: generator/adaptive planning and reconstruction, schemas/validation,
planning export, landscape reservation, CPU/WebGL/Canvas, physical street class,
zone inspector. Validate the same court/walk geometry across all consumers.
Campus lawns stay open, not procedural trees concealing invalid intersections.

## Gates and limits

Test verified positives, directory-name/unknown negatives, seeded non-selection,
compact/full capacity, fallback, corner rotation, all entrances connected, whole
parcel/court/road clearance, forged metadata, deterministic bytes and hinted edits.
Compare GJ/OJ/PocketBase/SQLite plus a maintained sparse eligible fixture using
actual CPU/WebGL/Canvas and complete source inspection. Report displacement
and explicit fallback rather than claiming every repository must gain a campus.

Bound court candidates, path tests and output sizes. If visual morphology does
not differ convincingly from existing GRID/RADIAL, do not call CP-01 complete.
Riverside variants, emergency vehicle access modeling, materials and lighting
remain separate work. No framework inference or role change is authorized.
