# ADR-047 — Scale-aware, seeded natural diversity

2026-10-19. The user explicitly requests restoration of lakes and varied counts,
locations and outlines of hills/ridges and flowing water. Earlier river-landscape
mode intentionally removed terminal lake caps and then unconditionally retained
one tributary and at most one ridge. That fixed stencil is not a varied world.

Add opt-in `--terrain varied-landscape`, terrain/0.5 and terrain-adaptive/0.5.
Keep all older presets/versions reproducible; do not mutate UCG/City or their IDs.
Nature still precedes district partition, streets, parcels and source assignment.
New nature may move districts/buildings; it is not a presentation-only change.
Use this mode's additional pre-seeding capacity reserve rather than drop files,
relax overlap/slope gates or keep retrying an identical failed layout forever.

Local seeded streams independently choose positions, orientations, eccentricity,
outlines, heights and count budgets. Budgets scale with initial area, then obey
geometric feasibility: lakes up to4, hill/ridge groups up to6, tributary paths0..3,
and sometimes a second through-flowing river. Tiny domains reserve one feasible
main crossing rather than stack several bridge ramps. No unseeded runtime RNG,
forced lake/mountain at a source filename, or invented semantic infrastructure.

Independent lakes have level basins in the shared height field, with long gentle
transitions that preserve bridge/road grade limits. River/tributary endpoints
continue outside bounded urban growth. Terrain/0.5 alone permits up to48 feature
pieces,8 certified crossings and3 conditional tunnel candidates; old payloads
retain their stricter limits. A river uses several convex pieces: feature-piece
count is NOT the number of independent rivers. Tunnels are still built only if
an original source trip actually uses a feasible, fully certified crossing.

Acceptance: seed diversity corpus and level lake surfaces; real pipeline on
GJ/OJ/PocketBase/SQLite/Hanul and maintained fixture; all source files/relations,
strict grade/collision/access checks, byte repeats, old-mode goldens and actual
CPU/WebGL/Canvas review. Keep a clearly labelled terrain-only seed atlas separate
from real full-city renders. This is analytical procedural nature, not a claim
of hydrological simulation or unconstrained random placement.
