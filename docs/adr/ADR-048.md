# ADR-048 — Joined physical pavement and curb-clipped walking surfaces

2026-10-19. User reports broken-looking joints on riverside/winding streets and
pedestrian pavement visibly overlapping carriageways. Graded exports previously
drew each rectangular span independently and skipped joint geometry entirely.

Prepare one offline `world-street-mesh/0.1` for CPU, Canvas and WebGL. Use bounded
cross-section hulls at actual common vehicle nodes, avoiding unbounded acute
miters. Reject added joint faces intersecting full parcels, natural reserves or
campus commons; never join different bridge/tunnel levels as ground pavement.
Clip pedestrian/building-entry surfaces to actual vehicle curb footprints and
joint patches so the same physical area is not painted as both walkway and road.
Logical walking routes can cross existing asphalt; clipping the walking colour
does not sever access or invent a traffic-mode restriction.

Retain each certified ramp's original piecewise height law and tessellate common
ground against the shared elevation field. Emit explicit four-corner triangle
faces for both existing browser consumers; arbitrary polygons must not lose
vertices in their quad API. No textures, per-frame clipping, new draw passes,
source evidence, routing changes or World/City/UCG schema change.

Acceptance includes an isolated comparison with identical World/City/UCG/planning
bytes, curb-overlap and bend-clearance tests, real CPU/WebGL/Canvas outputs,
source-path inspection and Synthetic static-cache reuse. This repairs surface
continuity, not the canonical road graph or all future horizontal road smoothing.
