# ADR-051 — Campus diversity is a spatial composition, not six radial rays

2026-10-19 user correction:0.5 replaced rectangular repetition with repeated
sunburst emblems. Diverse yaw bins and valid source geometry did not satisfy
the visual goal. Preserve0.5 only for reproducibility, not as the new baseline.

Add explicit `campus-style fabric`, campus-plan/0.6. Use distinct non-radial
compositions: a meandering pedestrian mall, an open arcade around an irregular
commons, and staggered garden lanes. Commons outlines differ with the composition.
Derive local bearings from real adjacent streets and fit the actual neighborhood
polygon and terrain. Seeded choices are deterministic architectural variation,
not invented source meaning. Vary compositions within a precinct; do not stamp
an identical round hub and spokes at every activity center.

Keep complete original memberships, evidence eligibility, source-degree anchors,
graph-aware assignment, full parcel dimensions, terrain and protected macro roads.
Every retained frontage path must connect to actual commons/exterior access. If
the new complete precinct cannot fit, use an explicitly reported safe0.4/0.3
fallback, never the rejected0.5 fan or a tiny partial campus pocket. Existing
styles remain reproducible. New style/version enums are additive experimental
contracts, not changes to UCG/City or new product dependencies.

Acceptance includes topology/outline diversity on actual GJ/OJ neighborhoods and
several seeds, occupied buildings and real CPU/WebGL/Canvas comparisons, not only
angle counts. Verify exact source relations, no overlap/access regressions, stable
nearby growth, independent reconstruction, bounds and repeatability. Do not claim
all visual planning complete merely because the new suite passes.
