# ADR-053 — Seeded waterway topology, not a repeated Y stencil

2026-10-19. The user approved correcting main-river/tributary counts and forms.
All four delivered campus-fabric cases have one main and one two-segment branch;
terrain/0.5's large synthetic seed test did not establish real-corpus diversity.

Add explicit `--terrain watershed-landscape`, terrain/0.6 and
terrain-adaptive/0.6. Preserve every earlier preset and its canonical output.
This is bounded analytical environmental generation, not a drainage simulation
or an inference about code quality. UCG/City, source IDs and evidence do not change.

Plan one or two through rivers, then zero to three curved tributaries, including
tributary-to-tributary confluences. Counts depend on seeded local streams and
available scale; do not hardcode repository names or search seeds until a desired
image appears. Independent streams control alignment, bends, widths and joins.
Reserve water, banks and certified bridge approaches BEFORE source placement;
never paint extra water over an existing city. Keep lakes and uplands.

Add optional channel `waterways` records with stable environmental IDs, kind,
parentId, centerline and width. Keep centerline + tributaries as the shared
height-field projection (additional main paths are also in that projection).
Version-specific schema constraints retain old payload bounds. New bounds:
64 convex natural pieces, five waterways, 17 vertices per line, eight certified
crossings, three conditional tunnels. Reject budget exhaustion explicitly.
Independent reconstruction verifies topology/geometry, not caller labels.

Acceptance: real GJ/OJ/PocketBase/SQLiteBrowser comparisons without seed shopping;
report actual MAIN/TRIBUTARY counts and parent structure, not RIVER mesh tiles.
Inspect CPU and real viewer overview/confluence views, through-boundary ends,
continuous water/shore, no parcel/water overlap, full source access and exact
dependency identities. Test fixed-seed variety at realistic medium-domain scales,
deterministic double runs, hinted growth and frozen legacy cases. Geography
deliberately changes on switching presets; never claim cross-version frame reuse.
