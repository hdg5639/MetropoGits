# ADR-054 — Single-owner coplanar asphalt and clean intersection paint

2026-10-19. User screenshots show torn/striped junctions and riverside forks.
Reproduce GJ preview-runtime at fixed coordinates. The baseline really draws
overlapping coplanar span/joint triangles, causing visible depth conflicts; do
not mistake those black spikes for source links or redesign the whole city.

Revise offline world-street-mesh/0.2 to partition the existing pavement union
into deterministic, nonoverlapping same-level pieces. One class/width/ID owner
paints each region. Pick a joint's dominant street class explicitly rather than
whichever incident span is widest. Keep bounded bevel clearance checks; never
expand the road into parcels, river reserves or campus courts. Bridges/tunnels
keep separate certified height groups, not a false union with ground beneath.
Walking/entrance colour remains clipped at the actual carriageway curb.

Clip center dashes at overlapping same-level crossing/merge mouths, including
acute forks where a fixed half-width endpoint trim is insufficient. Preserve
phase on collinear atomic spans, original slope heights, and separate crossing
levels. This is paint suppression inside real pavement, not deletion of roads.
Both operations use bounded offline spatial indexes, with explicit exhaustion.

World, UCG, City, planning, natural features, buildings, streets, every exact
route/edge and Synthetic trajectory remain byte-identical. CPU/Canvas/WebGL
consume the same geometry; no per-frame clipping, extra draw passes, dependency,
schema change, new inferred communication or fabricated roundabout is added.

Acceptance: geometric same-level face overlap and paint-mouth tests, unchanged
union coverage, obstruction/grade/bridge regression cases and deterministic
ordering. Repackage real GJ/OJ/PocketBase/SQLite/bat; inspect the reported GJ
neighborhood and three actual close-ups at the same camera, not only overview.
Run source/role/route/Synthetic inspection and a fresh input pipeline. This fixes
visible pavement corruption; it does not claim to remove every awkward physical
fork or complete the separate structural road-network planning milestone.
