# ADR-055 — Polyglot evidence adapters and additive catalog release

2026-10-20. User explicitly requests broad language/framework/library support
and corresponding facilities, not just Java/Spring. Follow FR-018/019/020 and
the polyglot plan, retaining static-first architecture and exact source IDs.

Python uses stdlib AST; other new module adapters expose their bounded lexical
subset honestly. Import presence is not compiler binding or deployed runtime
usage. Local ambiguity, dynamic constructs, macro/preprocessor expansion and
unsupported syntax remain disclosed. Never execute target code or install its
dependencies. Existing Java and JS/TS adapters remain, including their limits.

Release catalog/0.2 and bundled catalog0.5.0 add named ecosystems and AST-format
signatures. Keep catalog/0.1 and prior releases byte-immutable; dispatch validation
by schemaVersion, rejecting unknown versions. UCG0.1 and City0.2 are unchanged.
Claim values/archetypes already have extensible string contracts; new facilities
do not require silently broadening their schemas. Preserve fallback rendering.

Role rules require explicit imported provider plus matching call, annotation,
inheritance or supported source-format evidence. An unused import may identify
technology, not a specialized role. Manifest declarations alone never prove
active services, databases, HTTP destinations or broker topics. Distinguish API
entrypoints, UI components, CLI terminals, test labs, data models, computational
facilities, workers and auth configuration without inventing new source files.

Every added rule has positive/near-match negative catalog facts and an official
API reference. Exercise real source syntax, aliases, shadowing, comments, literals,
local lookalikes and missing imports in adapter fixtures; facts-only tests are
not proof that a parser recognizes a whole framework. No upstream source is
redistributed; unknown documentation licensing is recorded as NOASSERTION.

CPU/Canvas/WebGL facility geometry must use the same bounded envelopes and
deterministic orientation. Do not reflow geography to showcase the new models.
Existing gates/test compound facilities remain promoted at every LOD. Record
real multi-repository source/graph/scene/render evidence and remaining limits.
