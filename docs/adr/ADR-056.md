# ADR-056 — Source-purpose precincts and optional mountain ranges

2026-10-21. User requests campuses/buildings that express actual code purpose,
not repeated boxes, and optional true mountains rather than mandatory small hills.

Deliver two opt-in vertical slices; retain old style/terrain results. UCG0.1,
City0.2, source IDs, roles and dependency evidence stay unchanged. Do not claim
inferred architecture is measured runtime flow or invent facilities/entities.

1. `--campus-style programmed` (campus-plan/0.7): select architectural program
   from existing evidenced member roles, choose real anchors using roles AND
   graph affinity, adapt nonradial commons to that program. Keep mixed source
   membership, original directory ownership, frontage, whole-neighborhood and
   retained-external-connectivity guards. Explain the actual anchors/members.
2. `--building-style purposeful`: export-only bounded building arrangements
   based on existing roles, declaration counts and observed local fan-in/out.
   Paired same-World output changes silhouettes, not World geography, source
   claims, doors, roads or original trips. Generic remains unknown. CPU/Canvas/
   WebGL share compiled rotated parts; no per-frame generation. Preserve
   persistent gate/test aggregates and their exact inspectable membership.
3. `--terrain mountain-landscape` (terrain/0.7): seeded zero-or-more real mountain
   reserves, tall multi-peak ridges with shoulders/rock faces, not scaled cones.
   Generate before urban placement; buildings/streets must respect reserves.
   Existing watershed rivers/lakes, ground-grade, crossing, conditional tunnel,
   clipping, resource and independent reconstruction checks remain strict.
   Old terrain presets/versions remain reproducible and untouched in meaning.

Experimental World schema only receives additive style/version/terrain cases;
no existing enum is removed or repurposed. Record the new options in CLI/docs.
Same seed is repeatable, different seeds can have no mountains; do not force one
peak onto every map. Visual metaphor and procedural terrain are not code facts.

Validation: real maintained source -> UCG -> City -> World; before/after images
at equal cameras, generic corpus case, exact source/trip conservation, all-source
access, overlap/grade checks, hinted stability and repeated canonical artifacts.
Use purposeful small/mixed fixtures plus GJ/OJ/PocketBase as feasible. Prioritize
large visible distinctions over tiny roof-polish loops; do not hide broken roads
with landscaping or produce mock-ups instead of renderer evidence.

## Delivered checkpoint

The opt-in slices are implemented. Mountain mode uses a bounded continuous
triangular ridge surface with unequal summits, rock slopes and broad shoulders.
Its `HILL` feature kind remains compatible with existing reserve/conditional
tunnel consumers; `landform=MOUNTAIN_RANGE` distinguishes the new subtype.
Heights are 55–160 visual world units above local ground, not geographic metres.
Zero to two ranges may fit; small domains can contain none. No seed guarantees
a mountain or an automatically constructed tunnel.

CPU and WebGL framing include the actual mountain mesh only in terrain/0.7.
Old height constraints and old terrain/presentation behavior remain intact.
Programmed campus and mountain cases are accepted in both experimental World
and Planning schemas. Existing public UCG/City contracts are unchanged.

GJ/OJ/SQLiteBrowser and a maintained small source fixture were rendered and
validated. Large GJ repeat packages match all17 artifact hashes; nearby source
growth preserves previous terrain and occupied frames in the focused fixture.
See QUALITY_LOG.md for commands, exact revisions, measured results and limits.
