# ADR-057 — Campus-scale landmarks and outward, proportionate mountain surfaces

2026-10-21. Maintainer feedback: tiny per-file variants do not give a campus
identity; use a few large, inspectable source complexes. Mountain0.7 is too steep
and its downward-facing mesh incorrectly exposes the interior under backface
culling. Correct actual geometry before optional material detail.

- Mountain0.8 keeps the0.7 footprint, reserves, water and independent seed/count
  decisions, but bounds relief by ridge width and reduces its vertical scale.
  Version0.7 canonical terrain remains reconstructible; new generation uses0.8.
  Render export corrects old mountain face orientation without modifying saved
  source/world payloads. New and old meshes must face outward; do not disable
  culling/depth or add transparent camouflage.
- Optional `--campus-landmarks` is export-only, using persistent certified World
  compounds. A campus gets at most four complexes, each built from actual nearby,
  statically related source files, with mixed original roles and exact membership.
  Shared local reference targets are valid disclosed affinity, not additional
  peer dependencies. Preserve exact contributing original edge/target IDs.
  Each displays a shared podium/hall and a legible anchor, with purpose-sensitive
  silhouette. These are visual aggregates, not invented modules or research.
- Compound bounds may use clear interstitial space but must not consume another
  file, public/pedestrian road, court or protected nature. Preserve original
  graph/world, doors, source trips and source IDs. Fail safely if no fit exists;
  report rejected candidates, not cosmetic success. Old role compounds remain.
- Keep each complex across all zoom levels; explicit constituent expansion and
  filtering retain existing source-fidelity rules. CPU/Canvas/WebGL share the
  compiled physical model. No per-frame planning or additional draw pipeline.

Verify real before/after mountain backface geometry and GJ/OJ/unknown corpus
renders, full source counts/trips and independent compound clearance; add bounded
positive/negative fixtures, schema, determinism and existing aggregation tests.
