# ADR-059 — Evidence-gated architectural recipes, shared offline meshes

2026-10-21. The maintainer requests application of the Procedural Architecture
Catalog proposal. Its scene-field example is explicitly not an approved schema
migration. Implement an additive `--building-style catalog` World export first.

- Keep UCG/City/World/Planning bytes, stable source IDs, terrain, parcels, yaw,
  original entrances, exact source trips and certified compound membership.
  Catalog names are private presentation recipe IDs, not new City archetype enums.
- Compile the85 proposed recipes from a bounded reusable primitive grammar:
  cuboid, chamfered prism, gabled/sawtooth roofs, drum and dome. Parameterize by
  existing rotated envelope/height and independently seeded shape/roof/facade
  streams. No source-size metrics or runtime throughput are invented.
- Auto-select only variants supported by DIRECT/RESOLVED source-role evidence.
  TEST does not establish simulation/benchmarking; AUTH does not establish tokens;
  generic models never acquire a database engine. Technology-specific choices
  require local usage evidence, not a repository-wide declared dependency.
  Dormant proposal recipes remain prototypes, not claims of analyzer support.
- Compile one private model with source-linked faces and surface hints offline.
  CPU SVG, Canvas fallback and WebGL consume the same faces. Mesh additions stay
  inside the existing footprint/height; fail on invalid recipes/budget overflow.
  Reuse existing triangle batching, selection, cached shadows and Synthetic.
- Restyle only existing certified aggregates and retain their membership/proof,
  conservative picking envelope, reversible expansion and source path highlighting.
  Do not create a campus or new landmark merely to showcase a recipe.

Deliver a substantial visible slice rather than counting names: actual matched
corpus renders, grayscale silhouette atlas, source inspectors, bounding/normal/
determinism tests, unknown-input fallback and measured renderer costs. Report
which recipes actually occur;85 recipes is not85 proven semantic categories.
