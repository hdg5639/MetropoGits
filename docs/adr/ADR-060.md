# ADR-060 — Source-affinity facility sites before campus address assignment

2026-10-21. The maintainer explicitly requests variable architectural scale
and campus redesign. Extend the existing opt-in World planner with a new estate
style; do not replace the analyzer, City schema or working fallback engine.

- Determine source groups and their site capacity BEFORE fitting frontage and
  before assigning individual source addresses. Use only actual static edges
  and disclosed shared LOCAL file targets; never external-package popularity.
- A compound site is a derived physical reservation, not a new source entity.
  Variable multi-address sites are subdivided into the retained file-level
  inspection layer. Persistent, certified complexes are their visible massing.
- Source IDs, roles, evidence, directory ownership and original City dimensions
  remain unchanged. Existing World validation of each source address remains
  strict; a separate independent reconstruction checks the added site plan.
- Keep shared promenades/courts and primarily perimeter vehicle circulation.
  No public walkway may cut through a certified complex. Small source access
  spurs are reconstructed as exact new-layout inspection trajectories, not
  invented source relations. Campus interior positions may change; do not claim
  old World route coordinates are byte-identical after actual replanning.
- Calculate program area/contiguity pressure before district allocation, but
  record unmet pressure instead of forcibly growing unrelated terrain in this
  first slice. Enlarge individual physical envelopes and automatic land growth
  only with their separately reconstructed next-stage contract.
- campus-plan/0.8 extends World/Planning schemas additively. Source file size,
  geometry/source conservation and evidence checks remain strict. Larger-site
  infeasibility is disclosed; connectivity/capacity failure may retain the
  actual programmed style, never label that fallback a successful estate.
- Existing campus styles/defaults and saved worlds retain their behavior.
  Record opt-in planner style/version; reuse hints only for compatible styles.
- No per-frame planner, unsafe source execution, AI/runtime service or new
  renderer dependency. Explicitly report fit fallback and rejected compounds.

This slice does not redefine source-file widths/heights. General individual
program-sized envelopes remain a separate contract extension, not a reason to
remove existing size/overlap assertions. See ARCHITECTURAL_SCALE_PLAN.md.
