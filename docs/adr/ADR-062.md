# ADR-062 — Deterministic cold-start campus geography prepass

2026-10-22. Extend ADR-061's optional precinct workflow without replacing its
existing algorithms or changing the UCG/City/World schemas.

- Add explicit `--campus-bootstrap`, requiring campus/precinct mode and no
  supplied previous World. Old defaults, old modes and saved worlds retain
  their meaning. The option is not a promise that every source tree has space
  for a campus or that arbitrary seeds can violate protected nature.
- Compute one deterministic programmed geography prepass using the SAME source
  graph, city, seed, namespace, terrain and placement options. Stop after real
  bounded land/capacity planning, before physical street atomization, dependency
  routing, tunnels, surface meshing or rendering. No target code execution.
- Its private PlanningFrame is an internal transient layout hint, not a valid
  World artifact. Never export it, load it from an external cache as if newly
  computed, or claim it passed final World/evidence validation.
- Reuse that geography through the existing compatible migration path, then
  fit the actual precinct and construct/validate all physical infrastructure
  and source-backed trips. Preserve the programmed fallback when necessary.
- Record deterministic bootstrap version/provenance and zero baseline routing
  passes in diagnostics. No clocks, absolute paths or machine state in canonical
  output. Final normal schema, independent reconstruction, evidence, terrain,
  overlap and access validation are unchanged.
- Compare the prepass with a real fully generated programmed baseline, prove
  that routing is not called during the prepass, double-run canonical outputs,
  and test cold positive real repositories plus unsupported/negative cases.
  Report actual overhead, cold-fit limitations and visual findings honestly.

Consumers: World generator orchestration/private planning boundary, CLI and
diagnostics. No viewer runtime, external service or new schema version needed.
