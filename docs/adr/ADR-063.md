# ADR-063 — Separate legacy source-scene height from architectural capacity

2026-10-22. Accepted for the explicitly requested removal of the10-unit ceiling.
Authority: maintainer's mandatory redesign and immediate height-limit request.

The generic scene default10 is not a measured code metric or a physical law.
Reusing it as an architectural maximum kept unrelated building systems tiny.
Do not replace10 with another universal constant or map file imports to height.

- Keep canonical UCG/City/World/Planning and stable source IDs unchanged.
- Catalog0.4 derives a separately versioned physical-height/0.1 capacity from
  the chosen architectural form and actual horizontal span. No minimum with
  the legacy height. Footprint, frontage, source ownership and roads stay fixed.
- Compiled view models carry architectural `height` and original `sourceHeight`;
  profiles record the capacity, form, span and version. World-view/0.2 marks
  this derived view contract. CPU and WebGL consume the same compiled geometry.
- Independently reconstruct the capacity and check every part/mesh vertex;
  preserve horizontal collision bounds and reject invalid/nonfinite dimensions.
  This does NOT weaken the canonical World validator or modify its input.
- Retire reference-skyline massing/height modulation from catalog0.4. Keep the
  old module/artifacts as legacy diagnostics, not a master planner. File-level
  incoming count must not turn utilities into skyscraper headquarters.
- Semantic/purposeful/architectural modes and saved artifact bytes retain their
  old meaning. Original roles/confidence/proof do not change. Unknown stays
  unknown even when its neutral architecture has a taller physical envelope.
- UI discloses legacy versus architectural height; camera, LOD, picking, shadows
  and SVG frame the physical model. Package manifest pins the policy version.

This fixes a capacity coupling, NOT the mandatory master-planning redesign.
Large horizontal parcels, terrain-aware capacity replanning, UrbanCharacterProfile
and composed downtown/campus typologies remain tracked separately. Form ratios
are temporary architectural proportions, not claims of repository importance.
