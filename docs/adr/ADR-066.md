# ADR-066 — Admit physical architectural land before compiling urban massing

2026-10-22. Explicit maintainer authority: mandatory redesign §§6–9, followed
by the request to implement spatial demand and replace chopstick buildings.

Add opt-in `--building-style urban`. Preserve every existing mode and the
canonical UCG/City/World/Planning/source-size validators. Derived world-view/0.3
explicitly permits a different physical envelope backed by urban-land/0.1;
never claim it is the original source-address footprint.

1. Derive program-sized requests from verified roles and district spatial demand,
   before selecting/compiling a massing. Unknown files request neutral land only.
2. Reassign unused address-plot reserves within the same neighborhood, keeping
   the original front door, street point, yaw and exact source paths. Grow to the
   sides/rear; reserve all other source minimum envelopes, actual roads, protected
   nature, courts and certified campus complexes. Do not bulldoze greenery terrain.
3. Admit the complete requested area with fixed setbacks or retain the original
   address and record DEFERRED_REPLAN. No shrinking all designs to a tiny slot,
   silently deleting a file, changing an edge or fabricating a company identity.
4. Save exact source/allocated envelopes, request/evidence, decision and work
   counts in checksum-covered urban-land.json. Independently reconstruct the plan
   and verify physical clearance and source ownership; canonical World validation
   remains strict and is not bypassed by a larger derived envelope.
5. Compose a small modern massing system using actual admitted aspect ratios:
   broad slabs, setback volumes, podium/tower, connected wings and larger twin
   forms. Neutral architecture is not proof of a headquarters or runtime service.
   Use the existing district height allocation, not per-file import ranking.
6. CPU/WebGL, picking, shadows, framing, foundation and tree clearance consume
   identical compiled physical models. Existing certified groups remain persistent
   and retain their meshes, source membership and explicit member expansion.

This first admission pass consumes existing road-cut land; it is NOT the five
distinct master planners, a new road network, or full local reallocation after
insufficient capacity. Deferred requests remain an explicit next planning task.
Original World parcels are compatibility/address hints, not claimed as the new
physical lot boundaries. No public canonical contract or source ID is broken.
